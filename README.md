# Image Processing Laboratory

## Description

This project is an interactive **Image Processing Laboratory** developed using **Python and Streamlit**.

The application provides a web-based interface for working with images and demonstrating fundamental image processing techniques. Users can provide an image, perform processing operations, and view the results directly in the browser.

## Features

- Image Upload
- Image Selection
- Image Preprocessing
- Grayscale Conversion
- Image Filtering
- Image Smoothing
- Edge Detection
- Image Enhancement
- Kernel-Based Processing
- Processed Image Visualization
- Interactive Streamlit Interface

## Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- Pillow
- Scikit-Image

## Image Processing Techniques

### Grayscale Conversion

Converts a color image into grayscale to simplify further image processing.

### Image Filtering

Applies filtering operations to modify image information and reduce unwanted variations.

### Image Smoothing

Reduces noise and produces a smoother image.

### Edge Detection

Identifies important edges and boundaries present in an image.

### Image Enhancement

Improves the visual appearance and useful details of an image.

### Kernel-Based Processing

Uses processing kernels to perform transformations and extract information from images.
